# Text Management

文本资产包括训练提示词、案例说明、Rubric、条款样例和后台政策说明。

## 分类

- `prompt`：训练总控、学员作答、评分复盘等提示词。
- `case`：案例材料、出题要求、参考风险点。
- `rubric`：评分规则、分项扣分标准。
- `clause`：可复用条款样例。
- `policy`：后台运营、审计、发布和合规说明。

## 管理规则

1. 任何影响评分或训练输出的文本变更，都应留下审计记录。
2. 重大文本变更应进入 `VERSION_LOG.md`。
3. 真实合同材料进入案例库前必须脱敏。
4. 训练材料不得伪造法条、案例或监管文件。
5. 后台导出的 `contract-harness-state.json` 可作为版本归档材料提交到仓库。
